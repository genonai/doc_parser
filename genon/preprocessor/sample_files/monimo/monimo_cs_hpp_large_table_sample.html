카드 분실 재발급 상세 처리 절차

단계처리 내용확인 사항
ROW-01ROW-01-START 고객이 카드 분실 사실을 확인하면 앱이나 고객센터를 통해 즉시 분실 신고를 접수합니다. 신고가 완료되는 순간 기존 카드의 결제, 현금서비스, 자동화기기 출금 기능이 모두 정지되며 접수 번호가 발급됩니다. ROW-01-END본인 명의 휴대전화와 생년월일을 확인합니다.
ROW-02ROW-02-START 상담원은 최근 승인 내역과 고객이 기억하는 마지막 정상 거래를 비교하여 부정 사용 의심 건을 확인합니다. 고객이 승인하지 않은 거래가 있으면 사고 접수 번호를 추가로 생성하고 조사 담당 부서에 전달합니다. ROW-02-END거래 일시, 가맹점명, 승인 금액을 기록합니다.
ROW-03ROW-03-START 재발급 신청 전에 등록 주소, 연락처, 영문 이름을 최신 정보로 갱신합니다. 주소가 오래되었거나 배송 제한 지역이면 수령 가능한 국내 주소를 새로 등록해야 하며 해외 주소로는 발송하지 않습니다. ROW-03-END주소 변경 이력과 우편번호를 확인합니다.
ROW-04ROW-04-START 고객은 기존과 동일한 카드 상품 또는 현재 발급 가능한 대체 상품 중 하나를 선택합니다. 단종된 상품은 동일 조건으로 재발급할 수 없으므로 연회비와 주요 혜택을 비교한 후 대체 상품 동의를 받습니다. ROW-04-END상품명, 연회비, 브랜드를 확인합니다.
ROW-05ROW-05-START 재발급 심사를 위해 본인 확인과 카드 이용 상태 점검을 수행합니다. 장기 연체, 거래 정지, 신용정보 변경 등 추가 확인 사유가 있으면 자동 승인이 보류되고 담당 상담원이 필요한 서류를 안내합니다. ROW-05-END심사 상태와 보완 서류 유무를 확인합니다.
ROW-06ROW-06-START 심사가 승인되면 새로운 카드번호와 유효기간으로 카드 제작을 요청합니다. 보안상 전체 카드번호는 고객에게 미리 안내하지 않으며 제작 진행 상태와 예상 배송일만 앱 알림으로 제공합니다. ROW-06-END제작 요청 시각과 배송 예정일을 확인합니다.
ROW-07ROW-07-START 제작이 끝난 카드는 등록된 배송지로 발송되며 영업일 기준 삼 일에서 오 일이 소요됩니다. 배송 기사가 방문하기 전에 고객에게 연락하고 본인 또는 사전에 지정된 수령인이 신분 확인 후 수령합니다. ROW-07-END운송장 번호와 수령인 정보를 확인합니다.
ROW-08ROW-08-START 카드를 수령한 고객은 앱의 카드 등록 메뉴에서 카드 뒷면의 정보를 입력하고 본인 인증을 완료합니다. 등록이 끝나기 전에는 오프라인 결제와 현금서비스를 사용할 수 없으며 등록 완료 알림을 확인해야 합니다. ROW-08-END카드 등록 완료 여부와 인증 시간을 확인합니다.
ROW-09ROW-09-START 기존 카드에 연결되어 있던 자동납부 항목 중 카드사가 자동으로 승계할 수 있는 항목을 조회합니다. 승계되지 않는 통신요금, 보험료, 정기 구독은 고객이 각 납부처에서 새 카드번호로 변경해야 합니다. ROW-09-END자동 승계 대상과 직접 변경 대상을 구분합니다.
ROW-10ROW-10-START 모바일 지갑과 간편결제 서비스에 정지된 카드가 남아 있으면 기존 등록을 삭제합니다. 새 카드를 등록할 때 서비스별 본인 인증이 다시 필요할 수 있으며 일부 서비스는 실물 카드 등록 후 이용할 수 있습니다. ROW-10-END간편결제 서비스별 재등록 결과를 확인합니다.
ROW-11ROW-11-START 분실 이후 발생한 부정 사용 의심 거래는 조사 결과가 확정될 때까지 별도 관리합니다. 고객은 요청받은 사실 확인서와 거래 이의 신청서를 기한 안에 제출해야 하며 조사 진행 상황은 앱에서 조회할 수 있습니다. ROW-11-END서류 제출 기한과 조사 상태를 확인합니다.
ROW-12ROW-12-START 모든 재발급 절차가 완료되면 기존 카드의 최종 정지 상태, 새 카드의 정상 등록 상태, 자동납부 변경 결과를 종합 확인합니다. 이상이 없으면 처리 완료 메시지를 발송하고 상담 이력을 종료합니다. ROW-12-END완료 메시지 발송 시각과 상담 번호를 기록합니다.
